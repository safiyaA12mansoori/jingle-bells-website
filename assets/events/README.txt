Jingle Bells event photographs
================================

Put school photos in the matching folder, then list them in assets/js/events-data.js.

Required folders:
  christmas/
  independence-day/
  annual-day/
  dahi-handi/
  school-picnic/
  red-day/
  raksha-bandhan/
  sports-day/
  fancy-dress/

Suggested filenames in each folder:
  cover.jpg
  01.jpg
  02.jpg
  03.jpg

How to add a new event:
  1. Create assets/events/your-event-id/
  2. Copy an object in assets/js/events-data.js
  3. Set id, title, description, category (festival | national | sports | activities), theme, cover, photos[]
  4. Leave date empty unless the school confirms it

Photos already on the site:

  Yoga Day    — assets/img/yoga-day-01.jpg … yoga-day-14.jpg

Only publish photographs with parent or guardian consent.
